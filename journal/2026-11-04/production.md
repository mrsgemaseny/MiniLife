# Производственные станции — 2026-11-04

Проверено до записи: импорт Godot без ошибок скриптов; production_requirements, field_mechanics и interaction_selection дали 0 failures; main.tscn прошла 90 кадров без ошибок. git diff --check для изменённых файлов крафта прошёл.

## Изменения

- ProductionRequirements — общий контракт наличия нескольких станков для меню и can_craft. Физический поиск в радиусе 3 тайлов исключает удаляемые объекты; строка активного окна не предоставляет станок.
- Бронзовая экипировка требует верстак и ore_smelter; кольчужный койф/рубахи/хауберк собираются на верстаке; железное оружие использует forge; стальная экипировка требует forge и mechanical_water_mill. Последняя объединяет привод мехов и молота, отдельного автомолота нет.
- Убрана взаимозаменяемость кузницы/верстака, костра/алхимического стола и простой печи/плавильни. Зерновой помол совместим с механической мельницей.
- Меню показывает все требуемые станции. Исправлена текущая регрессия _execute_craft: multiplier игнорировался и отправлялся мгновенный craft_requested. Теперь отправляется craft_batch_requested с нужным количеством.
- Бонус SmeltingSystem больше не умножает готовые мечи/доспехи кузницы. Бронзовая ковка занимает 60 секунд.

## Проверки

Production suite проверяет реальные записи каталога, отсутствие подмен станков, дальность и удаление, общие проверки UI/выполнения. Настоящая кнопочная функция меню запускает пакет x5, тест продвигает ItemAction и получает ровно 5 мечей с точным списанием материалов. При уходе станка из радиуса до завершения предмет и списание не происходят. Тестовый рецепт существует только в памяти процесса; сохранения не затрагиваются.

## Границы

Проволока/кольца пока абстрагированы расходом слитков. Отдельный автомолот, сеть мощности и автоматизация не реализованы. Старый FurnaceSystem с двухслотовой плавкой не переработан в рамках этого изменения; его формулы и рецепты каталога пока остаются двумя путями обработки. Полный аудит баланса сырья, топлива и всех времён производства не заявляется.
