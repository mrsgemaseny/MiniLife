## Устранение фейковой шахматной текстуры у прорастающих деревьев (2026-11-04)

- **Диагностика артефакта «серая шахматка» (checkerboard)**:
  - На скриншоте пользователя обнаружены серые прямоугольные блоки с шахматным фоном поверх лесного биома.
  - Первопричина: при регенерации срубленных деревьев через 3 игровых дня (`growth_stage == "small_tree"`) `ResourceNode` загружал файл `res://assets/sprites/world/growth/tree_small.png`. Данный файл (и аналогичные в папке `growth/`) содержал непрозрачные пиксели с нарисованной «прозрачной» шахматкой Photoshop (688x1536, opaque RGB).
  - Решение:
    1. Поврежденные файлы с фейковой шахматкой удалены из `assets/sprites/world/growth/`.
    2. В `ResourceNode._draw()` логика отображения `small_tree` переведена на пропорциональное масштабирование чистых, оригинальных текстур высокого разрешения с настоящим альфа-каналом: для сосны — `pine_tree.png`, для лиственных — `oak_tree.png` с процедурным fallback.
    3. Исправлен `get_visual_rect()` для стадии `small_tree` для корректного Y-Sort и клика мыши.
- **Верификация**: E2E тесты пройдены 100% OK (`E2E_ALL_SYSTEMS_VERIFIED_OK`), артефакт полностью устранен.

## Исправление рубки сосны и коллизии типов ресурсов (2026-11-04)

- **Проблема**: Сосна (`forest_pine`) в игре не рубилась топором и не ломалась киркой. Игрок получал взаимоисключающие сообщения об ошибке: топор требовал кирку («Requires a pickaxe to mine stone and ores!»), а кирка требовала топор («Requires an axe to chop trees!»).
- **Первопричина**:
  - В `scripts/entities/resource_node.gd` определение типа ноды базировалось на подстроках в строковом идентификаторе `node_def_id`.
  - В строке `node_def_id.find("ore") != -1` идентификатор `"forest_pine"` давал совпадение из-за слова `"f-ore-st"`.
  - В результате `is_rock` и `is_tree` одновременно выставлялись в `true`, блокируя добычу любым инструментом.
- **Решение**:
  - В `resource_node.gd` методы `can_harvest` и `harvest_channel` переведены на строгую проверку параметров дефиниции из JSON (`skill == "mining"` / `"woodcutting"`, `preferred_tool == "pickaxe"` / `"axe"`).
  - Устранена коллизия подстроки `"ore"`, гарантирована взаимоисключаемость флагов `is_rock` и `is_tree`.
  - В E2E Phase 7 добавлен регрессионный тест рубки `forest_pine` топором и блокировки добычи киркой.
- **Верификация**:
  - Все 13 фаз тестового комплекса пройдены на 100% (`E2E_ALL_SYSTEMS_VERIFIED_OK`).
  - Файлы из `LOCKED_FILES.md` сохранены без изменений.

- **Верификация**:
