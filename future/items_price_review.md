# Сверка каталога предметов

Источник: `data/items.json`; экспортировано предметов: 134.
CSV использует действующие ID, цены, вес и состав из игры. Это проект для плана, а не подключённый к игре новый каталог.
Тип поселения, срок порчи и точная точка производства в исходных данных отсутствуют. Для ремесла указана станция, для остальных — добыча; срок помечен «-». Эти поля требуют отдельного проектного решения.

## Обязательные позиции

Вместо общего «зерно» используется `wheat`, вместо «железо» — `iron_ingot`.
Отсутствуют в игре: `salt`, `rope`.
Повторяющиеся ID в исходном JSON: `silver_coin` x2, `gold_coin` x2, `torch` x2. CSV сохраняет все исходные строки; перед импортом в игру дубли надо разрешить.
